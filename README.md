# Data Handling & Visualization - Bài 01: Xây nền tảng tự học

## Mô tả
Repository này lưu trữ các bài tập thực hành và tài liệu nghiên cứu cho Bài 01 của môn Data Handling & Visualization. Dự án này tập trung vào việc:
- Thiết lập môi trường phân tích dữ liệu chuẩn mực với Python (Anaconda, VS Code).
- Xây dựng cheat sheet cá nhân dựa trên tài liệu chính thức (Documentation) của thư viện Pandas.
- Thực hành phân tích dữ liệu khám phá (EDA) trên tập dữ liệu Titanic.

## Cách chạy code
1. Clone repository này về máy tính của bạn:
   `git clone https://github.com/vitconngungoc/vitcoin-DHV.git`
2. Kích hoạt môi trường ảo chứa các thư viện cần thiết (yêu cầu đã cài đặt sẵn Anaconda):
   `conda activate dataviz`
3. Mở thư mục dự án bằng VS Code hoặc chạy lệnh sau trong terminal để mở bằng trình duyệt:
   `jupyter notebook`
4. Mở các file `.ipynb` (như `setup_test.ipynb` hoặc `titanic_exploration.ipynb`), chọn đúng Kernel `dataviz` và chạy từng cell code.
